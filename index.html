Free QR code generator, explained

Is it actually free?

Yes. Every feature, every format, every size. No sign-up, no watermark, no trial, no premium tier waiting to ambush you.

Do the codes expire?

Never. These are static QR codes: the content lives inside the code itself, so there is no subscription keeping it alive.

What happens to my data?

Nothing. The code is generated in your browser. What you type or upload never touches a server and is not stored anywhere.

Can I add my logo?

Yes. Drop a logo in the centre and the code switches to its strongest error correction so it still scans.

Can I track scans?

Yes, honestly. Add UTM tags to a link and scans show up in your own analytics. No redirect service, no middleman.

What can a QR code hold?

Links, text, email, Wi-Fi logins, contact cards, calendar events, phone numbers, SMS, WhatsApp chats and map locations. Download as SVG, PNG, JPG, WEBP or PDF.

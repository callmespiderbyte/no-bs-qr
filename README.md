# No BS QR: free QR code generator

A free QR code generator with no shitty branding, no hidden fees, no sign-up and no expiry.

A single-page QR code maker for links, plain text, email and Wi-Fi. It exports clean square-module codes as SVG, PNG, JPG, WEBP or PDF, and bundles several formats into one .zip.

## Private by design

- Everything runs in your browser. Your content is never uploaded.
- Nothing is stored. No cookies, no local storage, no analytics, no accounts.
- The only network requests are the open-source libraries and fonts the page loads (cdnjs and Google Fonts).

## Features

- Content types: link, text, email and Wi-Fi, plus contact card (vCard), calendar event, phone call, SMS, WhatsApp and location
- Optional UTM tracking on links, so scans show up in your own analytics without any redirect or third-party counter
- Optional logo in the centre (read locally, never uploaded), with error correction locked to H so it still scans
- Background and code colour, each with a transparent option, plus tonal presets
- Padding: none, slim, standard, roomy or an exact pixel value
- Optional border with its own thickness, colour, gap to the code and margin to the edge, with a live check that the gap stays scannable
- Checks what you type (links, email addresses, phone numbers, Wi-Fi passwords, event times, coordinates) and only builds the code once it's valid
- Copy to clipboard: SVG as code, everything else as a PNG image
- Error correction L, M, Q or H
- SVG as a single merged vector path, raster exports from 512 to 4096 px, vector PDF
- Multi-format download as a .zip

## Use it

Open `index.html` in any modern browser. No build step, no server.

To host it, import this repo on Vercel (no build settings needed) or drop `index.html` on any static host. `vercel.json` adds strict security headers.

## Pages

Every page is the same tool with a different tab pre-selected, plus its own title, intro and questions:

- `/` all QR codes, `/de/` German
- `/wifi-qr-code-generator/`, `/vcard-qr-code-generator/`, `/qr-code-with-logo/`, `/svg-qr-code-generator/`, `/whatsapp-qr-code-generator/`, `/event-qr-code-generator/`, `/email-qr-code-generator/`

Deep links work on any page: `?type=wifi`, `?format=svg`, `?open=logo`. Only these settings are read from the URL, never content.

## Editing

The pages are generated, so edit the source, not the output:

- `src/template.html`: the tool itself (layout, styles, script)
- `scripts/pages.mjs`: titles, intros and questions for each page
- `scripts/de-ui.mjs`: German interface text

Then run `node scripts/build.mjs` (Node 18 or later, no dependencies) and commit the generated files. Vercel serves them as they are.

## Search engines

- `sitemap.xml` and the page list in `llms.txt` are generated by the build
- `.github/workflows/indexnow.yml` notifies Bing and other IndexNow engines after each production deploy
- Google Search Console and Bing Webmaster Tools verification files live in the root; keep them

## For search engines and AI

- `llms.txt` gives AI assistants a plain-language summary of what the tool does
- `robots.txt` welcomes search engines and AI crawlers, and points to `sitemap.xml`
- Structured data (WebApplication, HowTo, FAQ, source code) and social preview tags live in `index.html`

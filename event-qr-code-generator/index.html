How an event QR code works

An event QR code stores the event name, location, date and time in the iCalendar format. Scanning it offers to add the event to the phone’s calendar.

Use it on posters, invitations, tickets and save-the-date cards. All-day events work too, and the end time is checked so it always comes after the start.

Times are saved as local time, so the event shows at the time printed on the poster.

How to make a free QR code

Event QR codes, explained

Does it work on every phone?

Most iPhone and Android cameras recognise calendar QR codes, though some scanner apps show the text first. Test with the phones your audience uses before you print.

Can I make an all-day event?

Yes. Tick All day and skip the times.

What if I leave out the end time?

The event is set to one hour long.

Is it actually free?

Do the QR codes expire?

Never. These are static QR codes: the content lives inside the QR code itself, so there is no subscription keeping it alive.
